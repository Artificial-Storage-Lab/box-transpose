Key Insight
The 96 bytes in VRAM are identical to the original.

Only the stride tuple changed:
(12, 4, 1) → (1, 4, 12)

Now d varies fastest (stride 1) and w varies slowest (stride 12), so scanning logically in d,h,w order jumps across VRAM instead of scanning it sequentially.
